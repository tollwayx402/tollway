x402 · pay-per-request

Toll gates for your HTTP routes.

Return a 402, verify the payment, serve the 200. One middleware turns any route into a paid API — priced per request, settled on-chain, no account required.

Start collecting tolls
server.js — a paid API in 20 lines 
import express from "express";
import { tollway, coinbaseFacilitator } from "@tollway/gate";

const app = express();

app.use("/v1/report", tollway({
  price: "$0.004",
  network: "base-sepolia",
  payTo: process.env.TW_ADDRESS,
  facilitator: coinbaseFacilitator(),
}));

app.get("/v1/report", (_req, res) => {
  res.json({ report: "the paid content" });
});

app.listen(3000);

How it works

Three status codes. That's the whole protocol.

Tollway speaks x402 — the payment-required flow HTTP always reserved but never shipped. No API keys, no checkout pages, no invoicing.

402

Challenge

An unpaid request gets a signed challenge: the price, the network, and where to pay. Machine-readable, so agents handle it without a human in the loop.

✓

Verify

The client pays and retries with proof. Tollway verifies it through the facilitator — settlement-gated, nonce-cached, replay-safe.

200

Serve

Your handler runs exactly as before. The response carries a signed receipt header the caller can keep as proof of purchase.
